## 已验证范围

- 原五套视觉主题收敛为央国企成果、互联网工程、科研学术三种内容策略。
- 每种策略具有独立的阅读者、经历表达公式、技术保留规则、结果定义、区块优先级和禁用模式。
- 央国企策略明确将“解决了什么问题、个人承担什么、如何协同落地、形成什么结果”置于技术栈之前。
- 内容策略与头像、密度、页数预算、强调方向、字体和版式轴分离。
- Web `/cv` 显示三张策略卡、当前策略公式、内容说明、真实匿名预览和两两比较。
- 内容审计只统计可发布 Fact 中的经历类与结果类数量，并明确标记为组合层代理指标；不会补写缺失结果。
- 岗位简历候选改写阶段实际读取当前策略；央国企与互联网对同一纯技术栈 Fact 返回不同的证据约束诊断，并继续停在逐条确认前。
- 策略目录由独立 JSON Schema 完整校验；缺少表达公式、技术规则、区块指引或禁用项时系统启动即失败。
- v1 三预设和 V3.2 五主题在读取时确定性迁移且不写回用户文件；新 Campaign 正式产物拒绝所有旧 ID。
- 原 12 张参考图继续保存在 Git 忽略的 `profile/style-references/originals/`，未进入系统层或提交内容。

## 安全边界

- 参考图只用于结构提炼，不作为候选人 Fact 或 Evidence。
- 技术、结果、论文、专利、指标和个人贡献均须映射到可发布 Fact。
- 策略选择不能绕过 Fact Diff、逐条确认、30% 定制上限、头像授权、预览哈希或 manifest。
- 系统仍只准备材料并停在提交前，不执行外部申请提交。
