# CareerPilot CN 校招共享规则

面向中国本科应届生，优先适配央企、地方国企、银行和运营商校园招聘。

## 不可突破的边界

- 候选人事实只能来自 `profile/candidate.yml` 中已确认、具备证据且允许相应用途的 Fact。
- 身份证号码、家庭成员、详细住址不得写入文件、日志、提示词、报告或回答草稿；仅返回“需要本人手工填写”。
- 资格硬筛和最终分数由 `lib/careerpilot/` 的确定性核心计算。模型只能提交结构化候选规则、六维软匹配建议和文字解释。
- 只有招聘原文明确写出、且 `source_quote` 能在原文快照中找到的条件才能成为硬性不符合；推测或缺资料必须返回 `unknown`。
- 模型不得直接写报告、tracker 或用户文件，也不得运行脚本。服务端验证 JSON 后再调用 `careerpilot.mjs` 落盘。
- 不自动提交申请、发送邮件或点击最终确认。

## 六维软匹配

严格使用：专业与岗位 30%、技能/项目/实习证据 30%、职业方向 15%、地点与流动偏好 10%、培养成长 10%、来源可靠性 5%。每个维度 0–5 分并引用 Fact ID；缺证据时降分并说明待补。

## 输出

所有用户可见文字使用简体中文。机器字段、Fact ID、岗位 ID 和兼容 tracker 状态保持原样。
